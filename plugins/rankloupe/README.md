# Rankloupe for Cursor

SEO made simple.

Rankloupe gives your agent real SEO data and guided workflows, so its advice is grounded in your website instead of generic recommendations.

## What you can do

- Find and evaluate keywords
- Research competitors and content gaps
- Audit a website and prioritize fixes
- Analyze backlinks and find link prospects
- Track organic and Google Maps rankings
- Work with Google Search Console and Analytics data

The plugin includes nine skills that guide Cursor through complete SEO workflows, plus the hosted Rankloupe MCP server for live data and project management.

## Connect

Install the Rankloupe plugin from the Cursor Marketplace. The first time Cursor uses a Rankloupe tool, follow the OAuth prompt to sign in and approve the connection.

You need a Rankloupe account. Ask your administrator for one, or write to [support@cortexlabs.cloud](mailto:support@cortexlabs.cloud).

## Try it

- "Research keywords for my website and shortlist the best opportunities."
- "Audit my website and tell me what to fix first."
- "What does competitor.com rank for that I don't?"
- "Which pages are close to ranking in Google Search Console?"
- "Track my rankings for these keywords and summarize what changed."
